## 1. 회원가입 / 로그인 (Auth)

- **회원가입**: ID(중복체크), PW, PW 확인, 닉네임
- **로그인**: ID, PW 필드 및 [회원가입] 유도 버튼
- **특이사항**: 가입 완료 즉시 **웰컴 포인트(예: 1,000P)** 지급 안내 팝업 노출

---

## 2. 메인 페이지 (The World Map)

### GNB (상단바 — 전 화면 공통)
- **좌측**: 서비스 로고 아이콘 + **픽셀 경매 / PIXEL AUCTION** 텍스트
- **중앙 좌**: 현재 내 가용 AP 잔액 칩 (클릭 시 AP 충전 화면으로 이동)
- **중앙 우**: 서비스 메뉴 아이콘 7종 (아이콘 + 텍스트 라벨, 높이 76px)
  - 🔔 알림 / 🛒 장바구니 / 🛍 아이템샵 / ⭐ 시즌패스 / 🏆 랭킹 / 🏝 나의섬 / 👤 마이페이지
  - 활성 탭 하단 강조선 표시
- **우측**: 영토/좌표 검색 바 + ⚙ 설정 버튼
- **실시간 알림 아이콘**: 상회 입찰 시 빨간 배지 실시간 깜빡임

### 지도 영역 — 대륙 SVG 맵
- 8개 대륙이 실제 대륙 모티브의 유기적 SVG path로 표시
- **대륙 목록 및 등급**: 크리오 행성(S급), 글리치 행성(B급), 바이트 행성(B급), 크롬 행성(B급), 자유 행성(S급), 네온 행성(A급), 아리드 행성(A급), 포트 행성(C급)
- **호버 인터랙션**: 1.06배 확대 + 외곽 글로우 효과
- **트로피 조건 표시**: 각 대륙 내부에 `🏆 N+ 참여 가능` 표시
- **팬/줌**: 마우스 휠 줌(0.4x~4x) + 드래그 이동. 우상단 줌 컨트롤(+/−/⊡)

### 채팅 (토글 패널)
- 우하단 FAB 버튼(💬 + 미읽음 뱃지)으로 열고 닫음
- 열릴 때: 우측에서 300px 너비 플로팅 패널 슬라이드인
- 패널 내부: 온라인 인원 수, 채팅 메시지 목록, 메시지 입력 + 전송 버튼

## 3. 대륙 페이지 (Continent Page)

- **진입 조건**: 해당 대륙의 트로피 요구사항 충족 시에만 진입 가능
- **영토 그리드**: 등급별 시각 크기 차등
  - 👑 S급: 29px, 금색 테두리
  - 💎 A급: 24px, 시안 테두리
  - 🔷 B급: 18px, 초록 테두리
  - 🔹 C급: 12px, 회색 테두리
- **팬/줌**: 마우스 휠 줌 + 드래그 이동. 진입 시 전체 그리드 fit-to-screen

### 우측 사이드바 — 필터 패널
- **상태 필터**: 전체 / 경매 진행중 / 내 영토 / 미점령
- **등급 필터**: S / A / B / C (체크박스)
- **가격 범위 슬라이더**
- **정렬 기준**: 최신순 / 가격 낮은순 / 가격 높은순 / 마감 임박순

### 인라인 빠른 입찰 패널 (영토 클릭 시)
- 현재가 표시
- 입찰 금액 입력 필드 (기본값: 현재가 + 100)
- +500 / +1,000 / +5,000 누적 입찰 칩 버튼
- [즉시 입찰] 버튼 + 2.5초 성공 피드백

---

## 4. 영토 상세 및 입찰 (Full Page)

### 좌측 패널 — 내 입찰/관심 영토 목록
- **탭**: `입찰 중 N` | `관심 등록 N`
- **입찰 중 탭** 카드:
  - ✅ 최고 입찰 중: 초록 테두리 + 녹색 배지
  - 🔺 상회 입찰됨: 빨간 테두리 + 빨간 배지 + `🔺 재입찰` 버튼
  - `⚡ +100 즉시입찰` 버튼
- **관심 등록 탭**: 저장된 영토 목록 + 현재가 + 즉시입찰 + 관심해제

### 우측 패널 — 영토 상세 + 입찰 (2열 레이아웃)

**왼쪽 열 — 영토 미니맵**
- 등급별 그리드 크기: S급 12×12 / A급 10×10 / B급 8×8 / C급 6×6
- Zone 구분 색상 오버레이 (핵심/내부/외부)

**오른쪽 열 (위→아래)**
1. **가격 추이 차트** (선 그래프) — 기간 선택: 7일 / 30일 / 90일
2. **입찰하기 + 입찰 이력** (좌우 50%)
   - 입찰 패널: 현재가 / 금액 입력 / +500·+1K·+5K 칩 / [⚡ 입찰] 버튼
   - 입찰 이력: 최근 8건 (유저명 / 금액 / 시각)
3. **영토 스탯** (2열 격자): GP 생산 / 방어력 / 소유자 / 상태
4. **대륙 채팅방** (말풍선 형식, Enter 전송)

## 5. 마이페이지 (Dashboard)

- **프로필**: 닉네임, 계정 생성일
- **자산 섹션**: 보유 총액 / 사용 가능액 / 입찰 중(Locked) 도넛 차트
- **활동 탭**:
  - **참여 중인 경매**: 현재 내가 최고 입찰자인 영토 목록 + 남은 시간
  - **나의 영토**: 현재 점유 중인 영토 목록 (색상 변경 가능)
  - **낙찰 이력**: 과거 낙찰 기록 (영토, 가격, 날짜)

---

## 6. 랭킹 페이지 (Leaderboard)

- **필터**: 실시간 / 주간 / 월간 / 전체 기간
- **카테고리**: 영토 왕 / 자산가 / 트로피 / 대륙 지배자 (생산 효율왕은 모놀리식 릴리스 범위 제외)
- **UI**: 1~3위는 금/은/동 메달 아이콘과 함께 크게 노출, 4위부터 리스트 형태

---

## 7. 포인트 결제 및 충전

- **금액 선택**: 5,000P / 10,000P / 50,000P 등 정액권 선택 카드
- **결제 수단**: 테스트용 간편 결제 인터페이스 (가상 결제 프로세스)
- **완료 화면**: 충전 후 변경된 `available_point` 즉시 업데이트 노출

---

## 8. 영토/섬 내부 그리드 뷰

- **헤더**: 좌표/섬 표시, 보호 기간 남은 시간, 전체 방어력 수치
- **그리드 영역**: Zone 3/2/1 경계 시각적 표시, 각 건물 아이콘 + HP 바 + 레벨
- **사이드 패널 (우측)**: 현재 AP / GP / 글로벌 금고 잔액, 유닛 현황, 실시간 GP 생산량
- **하단 액션바**: [건물 추가] [유닛 배치] [금고로 이전]

---

## 9. 건물 건설 패널 (Build Panel)

- **건물 목록**: 아이콘 + 이름 + 크기 + 필요 GP + 효과 설명
- **Zone 제약 안내**: Castle은 Zone 1에만 배치 가능 표시
- **배치 미리보기**: 드래그 시 그리드에 활성 셀 표시
- **GP 부족 시**: 건물 비활성화 + 부족 금액 표시

---

## 10. 전투 화면 (Siege / Attack)

- **대상 영토 정보**: 좌표, 대륙명, 현재 Zone 보호 수치
- **목표 선택**: Zone별 공격 가능한 건물 리스트 (다음 Zone은 비활성화)
- **유닛 파견 설정**: 보유 유닛 수 입력, 공격력 합산 표시
- **공격권 확인**: 공격권 사용 확인 팝업
- **공성 카운트다운**: 선언 후 진행바 + 남은 시간 카운트다운
- **전투 결과 화면**: 공/방 유닛 손실, 약탈 자원, 디버프 또는 성 파괴 시 영토 인계 표시

---

## 11. 아이템 샵 (Item Shop)

- 헤더: 현재 AP / GP 잔액 표시
- 무적 시간 추가권 | 200 AP
- 일반 공격권 | 500 GP 또는 100 AP
- 정밀 공격권 | 300 AP
- GP 구매권 | 50 AP (일 5회 한도, 오늘 n/5회 표시)
- 각 아이템 구매 시 AP/GP 차감 확인 팝업

---

## 12. 시즌 패스 (Season Pass)

- 활성화 상태: 만료 D-N 카운트 + 혜택 요약
- 혜택: 섬 GP +50% / 일꾼 +1 / 토지세 면제 +2개
- 패스 없을 때: 혜택 목록 노출 + 구매 버튼 (1,000 AP)
- 구매 확인 팝업: AP 차감 후 즉시 활성화
- 중복 구매 시 남은 기간에 30일 누적 안내

---

## 13. 글로벌 금고 화면 (Global Vault)

마이페이지 내 💰 금고 탭에서 접근

- **상단 요약**: 현재 보관 GP / 최대 용량 / 다음 이전 가능 시각 (쿨다운)
- **영토별 저장소 목록**: 어떤 영토의 저장소에 얼마가 있는지 한눈에
- **이전 버튼**: [영토 저장소 → 금고] / [금고 → 영토 저장소]
- **쿨다운**: 쿨다운 없으면 즉시 이전, 쿨다운 중이면 남은 시간 표시
- **용량 업그레이드 버튼**: GP/AP 소비 금액 표시

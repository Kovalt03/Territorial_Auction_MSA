# 기획서 — 픽셀 경매 · 사이버 영토 전쟁

> Notion 원본: https://www.notion.so/3332efa4278d81aeb4a1eb426ba06530

---

## 1. 서비스 개요

**픽셀 경매 - 사이버 영토 전쟁**은 50×50 그리드 맵에서 영토를 경매로 획득하고, 그리드 위에 건물을 자유 배치하여 자원을 생산하며, 군사 유닛으로 다른 유저의 영토를 공격·방어하는 **실시간 전략 웹 게임**입니다.

> 핵심 경험: "내 땅을 건설하고, 키우고, 지키거나 — 빼앗아라."

---

## 2. 핵심 가치 & 차별점

| 가치 | 설명 |
|---|---|
| **경매 기반 영토 획득** | AP(현금 포인트)로 입찰 → 낙찰 시 영토 점유. 실시간 찬탈 + Anti-Sniping |
| **자유 건설 시스템** | 영토 내 그리드에 GP로 건물을 원하는 위치에 배치 → 기능이 결정됨 |
| **Zone 레이어 공격** | 외곽(Z3) → 중간(Z2) → 핵심(Z1) 순서로만 공략 가능 |
| **이중 저장소** | 영토 저장소(약탈 위험) + 글로벌 금고(완전 안전) |
| **Home Island** | 모든 유저에게 공격 불가능한 섬 기본 제공 |
| **공격권 시스템** | 공격 1회당 공격권 소모 → 신중한 PVP 유도 + GP 소비 싱크 |
| **이중 화폐 (AP/GP)** | AP(경매 전용) / GP(건설·생산·전투) 분리로 인플레이션 구조적 방지 |

## 4. 핵심 시스템 요약

### 4.1 이중 화폐 (AP / GP)
- **AP (Auction Point)**: 현금 충전으로만 획득. 경매 입찰·정밀 공격권 구매 전용
- **GP (Grid Point)**: 영토·섬의 생산소(Workshop)에서 생산. 건물 건설·유닛 생산·일반 공격권 구매·토지세 납부에 사용

**GP 흐름 (Territory-Scoped)**:
1. Workshop이 GP를 생산 → 해당 **영토 저장소(Storage 건물)**에 적립 (약탈 대상)
2. 영토 저장소 GP는 **해당 영토 내에서만** 건설·업그레이드에 직접 사용 가능
3. 일정량을 **글로벌 금고(Global Vault)**로 이전하면 어디서든 사용 가능 (공격 불가, 이전 쿨다운 존재)
4. 섬(Home Island) 저장소 GP도 동일한 방식으로 글로벌 금고로 이전 가능

### 4.2 Home Island (섬)
- 계정 생성 시 **자동 부여, 영구 보유, 공격 불가**
- 그리드(config) 위에 건물 자유 건설 가능
- 기본 GP 생산·유닛 생산 가능 (일반 영토보다 생산량 낮음)
- 글로벌 금고의 접근 거점

### 4.3 경매 시스템
- 50×50 맵의 영토를 AP로 입찰
- 입찰 조건: `Next ≥ Current × 1.05` AND `Next ≥ Current + 10`
- Anti-Sniping: 종료 1분 전 입찰 시 30초 연장 (최대 10분)
- **현재 최고 입찰자는 재입찰 금지** — 다른 유저에게 찬탈당한 후에만 재입찰 가능
- 낙찰 후 **보호 기간(config)** 동안 공격 수신 불가

### 4.4 건물 시스템

| 건물 | Zone 규칙 | 기능 | 공격 효과 |
|---|---|---|---|
| **성 (Castle)** | Zone 1만 가능 | 영토의 핵심 | HP 0 → 공격자 즉시 인계 |
| **저장소 (Storage)** | 어디든 | 영토 내 자원 보관 | HP 0 → 저장 자원 N% 약탈 |
| **생산소 (Workshop)** | 어디든 | GP 생산 | HP 0 → 생산량 감소 (T시간) |
| **병영 (Barracks)** | 어디든 | 유닛 생산 | HP 0 → 생산 중단 (T시간) |
| **방벽 (Wall)** | 어디든 | Zone 방어력 기여 | HP 0 → Zone 클리어에 기여 |
| **방어탑 (Tower)** | 어디든 | 자동 방어 + 방어력 | HP 0 → Zone 클리어에 기여 |

### 4.5 Zone 레이어 공격 시스템

```
Zone 3 (외곽) → Zone 2 (중간) → Zone 1 (핵심·성)
```

- 해당 Zone의 방어 건물 HP를 일정 비율(config) 이상 파괴 시 다음 Zone 접근 가능
- 각 공격 행위는 **공격권 1개** 소모

### 4.6 이중 저장소 시스템
- **영토 저장소**: 영토에 건설한 건물. 공격 시 약탈 대상.
- **글로벌 금고**: 계정 귀속, 공격 불가. 고정 용량(현재 업그레이드 미구현)
- 저장소 ↔ 금고 이전: **이전 쿨다운(config)** 존재

### 4.7 영토 등급 시스템

| 등급 | 등장 확률 | 기본 생산 배율 | 시작 경매가 배율 | 사전 건물 |
|---|---|---|---|---|
| 🟣 S | 3% | ×2.0 | ×3.0 | 2~3개 랜덤 |
| 🔵 A | 12% | ×1.5 | ×2.0 | 1개 랜덤 |
| 🟢 B | 35% | ×1.0 | ×1.0 | 없음 |
| 🟡 C | 35% | ×0.7 | ×0.8 | 없음 |
| 🔴 D | 15% | ×0.5 | ×0.5 | 없음 |

### 4.8 토지세 시스템

| 보유 영토 수 | 영토 1개당 일일 세율 |
|---|---|
| 1~3개 | 면제 |
| 4~6개 | 50 GP/일 |
| 7~10개 | 150 GP/일 |
| 11개 이상 | 400 GP/일 |

- **미납 처리 흐름**:
  1. GP 부족 → 경고 알림 발송
  2. 유예기간(config) 내 미납 시 → **최저 등급 영토부터 순차 강제 경매 전환**으로 자금 마련
  3. 강제 경매 낙찰 대금으로 세금이 충족되면 추가 처분 중단
  4. 강제 처분 대상 결정 시 **무적 상태·보호 기간 무시**
  5. 처분되는 영토마다 상실 정산: 저장 GP의 **80%를 원소유자 금고로 환수**(20%·식량 소멸), 방어 유닛은 홈 아일랜드로 퇴각(섬 수용량 초과분 소멸)
- Home Island는 세금 대상 아님

### 4.9 유닛 시스템

| 유닛 | 특성 |
|---|---|
| 보병 (Infantry) | 저비용, 공격·방어 범용 |
| 궁수 (Archer) | 방어 배치 시 보너스 |
| 기사 (Knight) | 고비용, 고공격력 |

- 식량은 **유닛 생산 예산**: 유닛 생산 시 그 위치 저장소에서 `foodCost × 수량` 1회 차감. 시간당 소모·아사는 없다.
- 농경지가 위치 저장소에 식량을 생산 → 축적 식량이 그 위치에서 만들 수 있는 유닛 총량을 규정

### 4.10 랭킹 시스템

시즌 기간 동안의 성과를 기준으로 하는 2개 카테고리 랭킹.

| | 카테고리 | 기준 | 갱신 |
|---|---|---|---|
| 🏅 | **시즌 영토 등급 보유** | 시즌 중 높은 등급의 영토를 오랫동안 보유한 시간 (등급 가중치 반영) | 주기적 배치 |
| 💸 | **시즌 경매 소비** | 시즌 중 경매 낙찰에 사용한 총 AP 금액 | 낙찰마다 갱신 |

> 트로피 점수는 전투 보상 리그(Bronze~Champion) 계산에만 사용하며 별도 랭킹 페이지로 노출하지 않는다.

#### 리그 티어

### 4.11 아이템 시스템

| 아이템 | 설명 | 구매 수단 | 가격 |
|---|---|---|---|

## 7. 경제 구조

```
AP (현금 충전)
  ├→ 경매 입찰 (영토 획득)
  ├→ 정밀 공격권 구매
  ├→ 아이템 샵 (무적 시간 추가권, GP 구매권)
  └→ 시즌 패스 구매

GP (생산소에서 생산)
  ├→ 건물 건설 / 업그레이드
  ├→ 유닛 생산 (병영)
  ├→ 글로벌 금고 용량 업그레이드
  ├→ 일반 공격권 구매
  └→ 토지세 납세
```

## 8. 주요 설정값 (Config)

```yaml
# 맵 구조
MAP_WIDTH: 50
MAP_HEIGHT: 50
TERRITORY_GRID_SIZE: 10
ZONE_BOUNDARIES: [2, 4]
ZONE_CLEAR_THRESHOLD: 0.5

# 전투 / 보호
PROTECTION_DURATION_HOURS: 12        # 획득 후 공성 불가 기간(보호). ※현재 코드 미분리 — 공성전 정립 때 확정
SIEGE_COUNTDOWN_MINUTES: 30
ATTACK_COOLDOWN_HOURS: 2
OCCUPATION_DURATION_HOURS: 24        # 보유 총 기간(만료 시 재경매). ※현재 코드는 3일 단일값으로 보호까지 겸함 — 공성전 정립 때 분리 예정

# 경제
BASE_GP_PRODUCTION_RATE: 1
HOME_ISLAND_PRODUCTION_RATE: 0.5
ADJACENT_BONUS_RATE: 0.1
GLOBAL_VAULT_BASE_CAPACITY: 10000   # GlobalVault 엔티티 기본값(고정)
VAULT_TRANSFER_COOLDOWN_MINUTES: 10
ATTACK_TOKEN_GP_COST: 500
ATTACK_TOKEN_AP_COST: 100

# 전투 계산
ATTACKER_LOSS_RATE: 0.3
ATTACKER_FAIL_LOSS_RATE: 0.5
DEFENDER_LOSS_RATE: 0.3
LOOT_RATE: 0.5                       # Zone3 저장소 GP 약탈률
TERRITORY_LOSS_TRANSFER_RATE: 0.8    # 영토 상실 시 저장 GP 환수율(나머지 소멸)

# 유닛 위치 간 이동
UNIT_MOVE_COST_GP: 10                # 유닛 1기당 이동 비용(출발지 저장소 차감)
UNIT_MOVE_MINUTES: 10               # 이동 소요 시간(도착 전 방어·배치 불가)

# 리그 경계
LEAGUE_SILVER_MIN: 500
LEAGUE_GOLD_MIN: 1500
LEAGUE_DIAMOND_MIN: 4000
LEAGUE_CHAMPION_MIN: 8000
```

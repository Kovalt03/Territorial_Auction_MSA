# 요구사항 정의서 (Functional Specs)

> Notion 원본: https://www.notion.so/Functional-Specs-3332efa4278d812c8e82fbd548671cb7

---

## 1. 그리드 및 영토 시스템

- **그리드 구조**: 전체 50×50 (2,500개 유닛) 고정형 맵
- **기본 단위**: 1개 영토(Territory) = 10×10 픽셀 단위
- **입찰 단위**: 최소 10×10 단위로 경매 참여
- **점유 정책**: 낙찰 후 특정 시간(T) 동안만 소유. T는 Config로 즉시 변경 가능
- **실시간 찬탈**: 경매 종료 전이라도 현재가보다 높은 금액 제시 시 즉시 임시 점유
- **Anti-Sniping**: 종료 직전 새로운 입찰 시 마감 시간 연장. 최대 연장 시간 설정 필수
- **다중 입찰**: 서로 다른 좌표의 영토를 동시에 여러 개 입찰·점유 가능
- **표현 방식**: 이미지 업로드 대신 단순 색상 지정 (점유 기간 내 제한된 횟수만 변경 가능)

---

## 2. 포인트 생산 시스템 (Passive Income)

- **실시간 생산**: 점유 중인 영토는 점유 기간 동안 지속적으로 GP를 생산
- **기본 생산 속도**: 영토 1개당 고정 생산 속도(예: 1P/분), Config로 즉시 변경 가능
- **인접 보너스**: 동일 유저가 상하좌우로 인접한 영토를 동시 점유 시 추가 보너스
  - 배율: `1 + (인접 점유 수 × 0.1)` (중첩 적용)
- **보너스 칸(Bonus Tile)**: 맵에 사전 정의된 특수 영토 점유 시 추가 생산 배율 적용
- **생산 중단**: `occupied_until` 만료 시 즉시 중단

---

## 3. 경매 로직 (Auction Lifecycle)

- **경매 순환 구조**: `점유 종료` → `유예 시간(Idle)` → `경매 시작`
- **실시간 찬탈**: 현재가보다 높은 금액 제시 시 즉시 입찰자 교체 + 기존 입찰자 환불
- **최소 상회 금액**: `현재가 × 1.05` 이상이면서 `현재가 + 10` 이상 동시 만족
- **재입찰 제한**: **현재 최고 입찰자는 재입찰 금지** — 다른 유저에게 찬탈당한 후에만 재입찰 가능
- **최소 점유 시간**: 낙찰 후 보호 기간 내 공격 수신 불가
- **연장 로직**: 종료 직전 경합 시 마감 연장, 최대 연장 시간 초과 불가

---

## 4. 알림 및 실시간 기능

- **상회 입찰 알림**: 내가 입찰한 지역에 더 높은 금액이 들어왔을 때 즉시 알림
- **경매 마감 임박**: 종료까지 얼마 없을 때 알림
- **관심 지역 알림**: 관심 지역으로 설정한 좌표가 경매 매물로 나왔을 때 알림
- **실시간 채팅**: 각 영토별 경매 페이지에서 참여자 간 실시간 채팅 가능

---

## 5. 데이터 히스토리 및 통계

- **가격 히스토리**: 특정 영토의 역대 낙찰 가격 데이터 보존
- **시각화**: 기간별 가격 변동 추이를 그래프로 제공
- **랭킹 시스템**: 시즌 기반 2개 카테고리 (시즌 영토 등급 보유, 시즌 경매 소비)

---

## 6. 포인트 및 결제

- **포인트 관리**: 가상 포인트 충전 시스템
- **트랜잭션 보장**: 입찰 시 포인트 차감과 기존 유저 환불은 원자적으로 처리
- **포인트 락(Lock)**: 입찰 시 `available_ap` → `locked_ap`로 이동. 낙찰 시 차감, 찬탈 시 복구

---

## 7. 랭킹 및 트로피 시스템

### 시즌 랭킹 (2개 카테고리)

- **시즌 영토 등급 보유 랭킹**: 시즌 기간 중 높은 등급의 영토를 오랫동안 보유한 유저 순위
  - 점수 = Σ(등급 가중치 × 보유 시간). 등급 가중치: S=4, A=3, B=2, C=1
  - 주기적 배치로 집계
- **시즌 경매 소비 랭킹**: 시즌 기간 중 경매 낙찰에 가장 많은 AP를 사용한 유저 순위
  - 낙찰 시마다 즉시 갱신

### 트로피 & 리그 (전투 보상 기준, 랭킹 페이지 노출 없음)

- **트로피**: 공격·방어 결과를 단일 점수로 통합. 하한 0
- **리그 티어**: 각 리그는 서브 티어 3단계로 구성 (3이 최하위, 1이 최상위). Champion은 단일 티어.

| 리그 | 서브 티어 | 트로피 범위 | 세부 경계 |
|---|---|---|---|
| Bronze | 3 / 2 / 1 | 0 ~ 499 | 0 / 167 / 334 |
| Silver | 3 / 2 / 1 | 500 ~ 1,499 | 500 / 833 / 1,167 |
| Gold | 3 / 2 / 1 | 1,500 ~ 3,999 | 1,500 / 2,167 / 2,834 |
| Diamond | 3 / 2 / 1 | 4,000 ~ 7,999 | 4,000 / 5,334 / 6,667 |
| Champion | — | 8,000+ | — |

- **시즌 종료 처리 순서**:
  1. 리그별 보상 지급 (GP + 공격권, Champion은 칭호 추가)
  2. 트로피 서브 티어 단위 강등 리셋: 1단계 하위 서브 티어의 최솟값으로 점수 조정
     - 리그 경계 강등 예: Gold 3 → Silver 1 최솟값(1,167), Champion → Diamond 1 최솟값(6,667)
     - Bronze 3 → 0 (하한선)
- **시즌 종료 트리거**: 관리자가 `seasons.ended_at`을 현재 시각 이전으로 설정 시 스케줄러(1분 주기)가 자동 감지. 멱등 보장.

- **리그별 보상 정책**:

| 리그 | GP | 일반 공격권 | 정밀 공격권 | 칭호 |
|---|---|---|---|---|
| Bronze | 100 | 0 | 0 | — |
| Silver | 300 | 1 | 0 | — |
| Gold | 600 | 1 | 1 | — |
| Diamond | 1,200 | 2 | 2 | — |
| Champion | 3,000 | 3 | 3 | "챔피언" |

### 시즌 관리

- **반자동 처리**: 관리자가 설정한 기간(시작일·종료일)으로 운영. 시즌 1은 구현 완료 후 수동 시작.
- 시즌 시작·종료는 관리자 설정값을 기반으로 스케줄러가 자동 처리

## 8. Home Island 시스템

- **자동 부여**: 계정 생성 시 섬 1개 자동 생성. 영구 보유, 경매 대상 아님
- **공격 불가**: 완전 안전 지대
- **그리드 건설**: 섬 내 그리드에 GP로 건물 자유 배치 가능
- **생산 제한**: 섬 기본 생산량은 일반 영토 대비 낮게 설정 (config). 인접 보너스 없음
- **글로벌 금고 연결**: 섬에서 글로벌 금고로 자원 이전 가능

---

## 9. 건물 건설 시스템

- **자유 배치**: 유저가 GP를 소비하여 그리드의 원하는 셀에 건물 배치
- **Zone 제약**: Castle은 Zone 1에만 배치 가능
- **건물 HP**: 모든 건물은 HP를 가짐. 공격으로 HP 감소, 0 도달 시 파괴 효과 발동
- **재건**: GP를 소비하여 파괴된 건물 수리 또는 재건 가능
- **업그레이드**: GP 소비로 용량/생산량/방어력 업그레이드
- **이동**: 같은 영토/섬 내 다른 빈 셀로 이동 (GP 소비 없음)
- **보관**: 그리드에서 제거하여 보관함(Inventory)에 저장. Castle은 보관 불가

---

## 10. Zone 레이어 공격 시스템

- **공격 방향 제한**: Zone 3(외곽) → Zone 2(중간) → Zone 1(핵심·성) 순서로만 공격 가능
- **Zone 클리어 조건**: 해당 Zone 방어 건물 HP 합계를 일정 비율(config) 이상 파괴 시 다음 Zone 해금
- **공성 카운트다운**: 공격 선언 후 일정 시간 뒤 전투 계산. 방어자에게 즉시 알림
- **전투 계산**: ATK = Σ(파견 유닛 공격력 합) vs DEF = Σ(방어 유닛 방어력 합 + 방어 건물 방어력)
- **결과 처리**:
  - 저장소 파괴: 영토 저장소 자원 N% 약탈 (글로벌 금고는 미영향)
  - 생산소 파괴: 생산량 감소 디버프 (T시간)
  - 병영 파괴: 유닛 생산 중단 (T시간)
  - 성 파괴: 공격자 즉시 인계(저장 GP 80% 공격자 금고·나머지·식량 소멸·방어 유닛 전멸) → 인계받은 공격자에게 보호 기간 재시작
- **보호 기간**: 경매 낙찰 후 `PROTECTION_DURATION_HOURS`(config) 동안 공격 수신 불가

---

## 11. 이중 저장소 시스템

- **영토 저장소**: 영토 내 건물로 건설. 공격 시 약탈 위험. 용량은 건물 레벨에 비례
- **글로벌 금고**: 계정 귀속, 공격 불가. 고정 용량 제공(업그레이드 미구현)
- **자원 이전**: 저장소 ↔ 금고 이전 가능. 이전 쿨다운(config) 존재
- **약탈 범위**: 저장소에 있는 자원만 약탈 대상. 글로벌 금고는 약탈 불가

---

## 12. 영토 등급 시스템

- **등급 부여**: 맵 초기 생성 시 S/A/B/C/D 등급 확률적 부여. 등급은 영구 고정
- **등급별 특성**:
  - S (5%): 생산 배율 ×3.0, 시작 경매가 ×3.0, 건물 3개 사전 배치
  - A (15%): 생산 배율 ×2.0, 시작 경매가 ×2.0, 건물 2개 사전 배치
  - B (35%): 생산 배율 ×1.5, 시작 경매가 ×1.5, 건물 1개 사전 배치
  - C (45%): 기본 배율 ×1.0
- **UI 표시**: 영토 팝업 상단에 등급 배지 항상 노출

## 13. 토지세 시스템

- **부과 주기**: 매일 자정 일괄 차감
- **누진세 구조**: 1~3개 면제 / 4~6개: 50 GP/일·개 / 7~10개: 150 GP/일·개 / 11개+: 400 GP/일·개
- **미납 처리 흐름**:
  1. GP 부족 → 경고 알림 발송
  2. 유예기간(config) 내 납부 시 처리 완료
  3. 유예기간 초과 시 → **최저 등급 영토부터 순차 강제 경매 전환**으로 자금 마련
  4. 강제 경매 낙찰 대금으로 미납 세금이 충족되면 추가 처분 중단
  5. **무적 상태·보호 기간 있어도 강제 처분 대상에서 제외되지 않음**
  6. 처분·점유 만료 영토마다 상실 정산: 저장 GP 80% 원소유자 금고 환수(나머지·식량 소멸), 방어 유닛 홈 아일랜드 퇴각(섬 수용량 초과분 소멸)
- **예외**: Home Island는 세금 대상에서 제외

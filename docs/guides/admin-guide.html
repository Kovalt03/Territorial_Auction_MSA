관리자 콘솔

경매·시즌·밸런스·사용자를 운영하는 관리자 전용 콘솔입니다. 일반 서비스와 분리된 /admin/login에서 시작하며, 관리자 권한 + 2차 인증(TOTP)이 필요합니다. 재화·상태·밸런스를 바꾸는 작업은 대부분 감사 로그에 남습니다.

/admin · ROLE_ADMIN · TOTP · AUDIT-LOGGED

🔐 최초 보안 설정 (운영 전 필수)
  1. 운영 가이드의 ADMIN_SEED_EMAIL / ADMIN_SEED_PASSWORD로 최초 관리자 한 명만 생성한다.
  2. /admin/login에서 로그인하고 TOTP를 설정해 인증 앱 코드를 사용한다. (최초 로그인은 인증 코드 생략)
  3. 시드 환경 변수를 제거하고 재기동한다.
  4. 외부 환경에서는 ADMIN_IP_ALLOWLIST를 반드시 설정한다.

⚠ 관리자 비밀번호 · TOTP 시크릿 · JWT · DB 비밀번호는 채팅 · 문서 · Git에 절대 기록하지 않는다.

04 · Audit

감사 로그

관리자 변경 이력과 사유를 확인한다. 모든 상태 변경의 추적 기준선.

감사 로그

/admin/audit-logs
관리자 · 감사 로그

무엇을 하나요

누가 · 언제 · 무엇을(action) · 어떤 대상에 변경을 가했는지 확인합니다. action 검색과 대상 필터를 지원하며, ‘보기’로 상세 변경 내용을 봅니다. 변경 후 결과 검증과 사고 대응의 근거입니다.

주요 작업

  • 감사 로그 조회 · action/대상 필터 조회
05 · Procedure

권장 운영 절차

  1. 대시보드 확인 — 장애·이상 징후와 현재 경매·시즌 상태를 먼저 본다.
  2. 대상 조회 — 사용자·영토·경매를 바꾸기 전 대상 ID, 현재 상태, 영향 범위를 확인한다.
  3. 최소 변경 — 필요한 최소 대상부터 처리한다. 대량 변경은 사유와 범위를 다시 검토한다.
  4. 결과 검증 — 변경 후 해당 화면과 감사 로그에서 결과를 확인한다.
  5. 사고 대응 기록 — 변경 시각 · 대상 · 사유 · 감사 로그 ID를 보존한다. DB 복구는 로컬 운영 실행 가이드 절차로 별도 수행한다.

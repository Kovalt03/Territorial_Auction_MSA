# v1.0.0-monolith 릴리스 기준점

## 목적

모놀리식 구현 완료본의 기능·성능·운영 기준을 고정하고, 이후 MSA 전환의 비교 기준으로 사용한다.

## 포함 범위

- Spring Boot + PostgreSQL + Redis 단일 백엔드와 React/Vite 프론트엔드
- 경매·영토·건물·자원·군사·공성전·길드·시즌패스·관리자 기능
- REST API와 STOMP WebSocket 실시간 갱신
- 로컬 운영 Docker Compose, Flyway 스키마 마이그레이션, production profile

## 검증 기준

- 백엔드: `./gradlew spotlessCheck test gatlingClasses`
- 프론트엔드: `npm run test:run`, `npm run build`
- 빈 PostgreSQL에서 Flyway V1 적용 후 Hibernate `validate`와 애플리케이션 기동
- 로컬 Docker UI의 일반 사용자·관리자 흐름 수동 확인
- 우선순위 혼합 Soak: 50 VU, 1시간, 71,665 요청, 실패 0건
- Render·Supabase·Upstash 외부 호환성 스모크: API health, Flyway, Redis TLS 캐시, CORS·SockJS, 정적 프론트 구성 확인

성능 수치와 실행 조건의 상세는 Git에 포함하지 않는 `report/load/`의 검증 보고서를 참조한다.

## 알려진 제한

- AP 충전은 실제 PG 연동이 아닌 mock 구현이다.
- 개인섬 연구·섬 확장은 준비 중이다.
- 이 문서는 외부 공개 서비스의 보안·가용성 인증을 뜻하지 않는다. Render Free의 512MB 한도는 현재 모놀리식 상시 실행에 부족하므로, 외부 구성은 호환성 검증용으로만 보관한다.
- 실제 실행과 운영 리허설은 로컬 Docker Compose 기준으로 수행한다. 외부 운영을 재개하려면 충분한 메모리의 인스턴스, 비밀 관리, 백업·복구 검증, OAuth 리디렉션 설정을 별도로 완료해야 한다.

## 태그 기준

이 문서와 운영 준비 변경이 `dev`를 거쳐 `main`에 병합되고 CI가 통과한 커밋에 `v1.0.0-monolith` annotated tag를 생성한다.

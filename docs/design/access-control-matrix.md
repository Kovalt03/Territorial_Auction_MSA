## 주요 기능 명세

### F-1. 회원가입 및 로그인

- **F-1.1 회원가입**: 아이디, 비밀번호, 닉네임 입력. 가입 시 `Wallet`, `NotificationSetting`, `HomeIsland`, `UserProfile` 자동 생성
- **F-1.2 로그인**: JWT 방식. 이후 모든 API 요청 헤더에 토큰 포함

### F-2. 포인트 및 자산 관리

- **F-2.1 AP 충전**: 외부 결제 API(가상)를 통해 충전. 성공 시 즉시 `available_ap` 업데이트
- **F-2.2 포인트 락(Lock)**: 입찰 시 `available_ap` → `locked_ap`. 찬탈 시 복구
- **F-2.3 최종 결제**: 낙찰 확정 시 `locked_ap` 영구 차감

### F-3. 영토 및 대륙 관리

- **F-3.1 실시간 지도 렌더링**: 10×10 단위의 영토 상태(경매중/점유중/유예)와 색상을 격자 형태로 출력
- **F-3.2 색상 변경**: 점유 중인 유저(`owner_id`)만 변경 가능. 점유 기간 내 3회 제한, `ColorHistory`에 기록

### F-4. 경매 시스템

- **F-4.1 자동 경매 생성**: `occupied_until` 후 유예 시간(10분) 경과 시 자동 `BIDDING` 전환
- **F-4.2 입찰 검증**: `현재가 × 1.05` 이상이면서 `현재가 + 10` 이상 동시 만족. 현재 최고 입찰자 자신 갱신 불가
- **F-4.3 Anti-Sniping**: 종료 1분 전 입찰 시 30초 연장 (최대 10분 초과 불가)
- **F-4.4 낙찰 처리**: 경매 종료 시 최고 입찰자 등록, 점유 기간(24시간) 설정

### F-5. 실시간 소통 및 알림

- **F-5.1 채팅 권한**: 로그인한 유저만 전체/대륙 채팅 참여 가능
- **F-5.2 상회 입찰 알림**: 내가 참여 중인 경매에서 최고가 입찰자가 바뀌면 즉시 푸시 알림 발송
- **F-5.3 관심 지역 알림**: 사용자가 설정한 `InterestGroup`(대륙) 내에서 새로운 경매 시작 시 알림 발송
- **F-5.4 알림 필터링**: `NotificationSetting`의 각 항목이 `true`인 경우에만 실제 발송 수행

### F-7. 포인트 생산 시스템 (Passive Income)

- **F-7.1 실시간 생산**: 점유 중인 영토마다 `base_rate`로 주기적 GP 생산 → 그 위치 저장소(`building_instances.stored_gp`) 적립 (비동기 스케줄러)
- **F-7.2 인접 보너스**: 동일 유저가 상하좌우 인접 영토 동시 점유 시 보너스 적용. 배율 = `1 + (인접 점유 수 × 0.1)`
- **F-7.3 보너스 칸(Bonus Tile)**: 사전 지정 특수 영토 점유 시 `BonusTile.multiplier` 추가 적용
- **F-7.4 생산 중단**: `occupied_until` 만료 시 해당 영토 생산 즉시 중단
- **F-7.5 수익 내역 조회**: 마이페이지에서 영토별 생산량 및 누적 수익 확인 가능

### F-8. Home Island 시스템

- **F-8.1 섬 자동 생성**: 회원가입 완료 시 `HomeIsland` 자동 생성
- **F-8.2 공격 불가**: 어떤 유저도 Home Island 공격 불가. 완전 안전 지대
- **F-8.3 그리드 건설**: 섬 그리드에 GP 소비하여 건물 자유 배치. Zone 및 Castle 기본 규칙 동일 적용
- **F-8.4 생산 제한**: 섬 GP 생산량은 `HOME_ISLAND_PRODUCTION_RATE`(config) 비율로 제한. 인접 보너스 없음
- **F-8.5 글로벌 금고 연결**: 섬 내 저장소에서 글로벌 금고로 자원 이전 가능 (쿨다운 동일 적용)

### F-9. 건물 건설 및 관리

- **F-9.1 건물 배치**: GP 소비, 건물 크기에 맞는 연속된 빈 셀 필요
- **F-9.2 Zone 제약**: Castle은 Zone 1에만, 영토당 Castle은 반드시 1개
- **F-9.3 건물 효과**: 배치된 건물 종류에 따라 영토 기능 다양화 (생산/저장/유닛생산/방어)
- **F-9.4 건물 HP**: 모든 건물은 HP 보유. HP 0 도달 시 효과 정지 + 파괴 상태
- **F-9.5 재건**: 파괴된 건물을 GP 소비하여 재건. HP 완전 복원
- **F-9.6 업그레이드**: GP 소비로 레벨업. 레벨마다 용량/생산량/방어력 증가
- **F-9.7 건물 이동**: 같은 영토/섬 내 다른 빈 셀로 이동. GP 소비 없음. Castle은 Zone 1 내에서만 이동 가능
- **F-9.8 건물 보관**: 그리드에서 제거하여 보관함에 저장. Castle 보관 불가. 레벨·HP 유지
- **F-9.9 보관함 조회**: 보관 중인 건물 목록(종류, 레벨, HP) 확인 가능
- **F-9.10 보관함에서 배치**: 보관함의 건물을 재배치. GP 소비 없음. Zone 제약 동일 적용

### F-10. 이중 저장소

- **F-10.1 영토 저장소**: Storage 건물 건설 시 활성화. 공격 시 약탈 위험. 건물 레벨에 비례해 용량 증가
- **F-10.2 글로벌 금고**: 계정 생성 시 기본 용량으로 자동 생성. GP/AP로 용량 업그레이드 가능. 타 유저 공격 불가
- **F-10.3 자원 이전**: 영토 저장소 ↔ 글로벌 금고 상호 이전. 이전 후 `VAULT_TRANSFER_COOLDOWN`(config) 동안 재이전 불가
- **F-10.4 약탈 범위**: Storage 건물 파괴 시 영토 저장소 자원의 N%만 약탈 가능. 글로벌 금고는 약탈 불가

### F-11. 전투 / 공성 시스템

- **F-11.1 공격 선언**: 공격권 1개 소모 + 대상 영토의 Zone과 목표 건물 지정 → SiegeEvent 생성. 방어자에게 즉시 알림
- **F-11.2 Zone 순서 제약**: 이전 Zone이 클리어되지 않으면 다음 Zone 공격 불가
- **F-11.3 공성 카운트다운**: `SIEGE_COUNTDOWN_MINUTES`(config) 경과 시 자동 전투 계산
- **F-11.4 전투 계산**:
  - ATK = Σ(파견 유닛 attack_power × 수량)
  - DEF = Σ(방어 유닛 defense_power × 수량) + Σ(Zone 방어 건물 defense_power)
  - 성공: ATK > DEF
  - 건물 HP 감소: 잉여 ATK를 Zone 방어 건물들에게 현재 HP 비율로 분산 적용
  - 공격자 손실(성공): `파견 수 × (DEF / ATK) × ATTACKER_LOSS_RATE`(기본 0.3)
  - 공격자 손실(실패): `파견 수 × ATTACKER_FAIL_LOSS_RATE`(기본 0.5)
  - 방어자 손실(공격 성공): `방어 수 × (ATK / DEF) × DEFENDER_LOSS_RATE`(기본 0.3)
- **F-11.5 결과 처리**:
  - Storage 파괴: 영토 저장소 자원 N% 약탈 (DB 트랜잭션 보장)
  - Workshop 파괴: 생산량 제로 디버프 T시간
  - Barracks 파괴: 유닛 생산 중단 T시간
  - Castle 파괴: **공격자 즉시 인계**(저장 GP 80% 공격자 금고·나머지·식량 소멸·방어 유닛 전멸·영토 점유 이전 + 보호 기간 재시작)
- **F-11.6 공격 쿨다운**: 공격 실패 후 `ATTACK_COOLDOWN_HOURS`(config) 동안 같은 영토 재공격 불가
- **F-11.7 보호 기간**: 경매 낙찰 후 `PROTECTION_DURATION_HOURS`(config) 동안 공격 수신 불가. `territories.protected_until`로 점유 기간(`occupied_until`)과 분리 관리 — 보호 < 점유
- **F-11.8 공성 건물**: 공격 선언 시 대상 영토 그리드에 STAGING(주둔지, 1개 필수) / TOWER(공성탑) / SUPPLY(보급소)를 함께 건설. STAGING 기준 체비셰프 거리 1 인접·좌표 중복 불가·총 8개 이하. 건설비는 금고 GP 차감. 투입 병력 상한 = STAGING 레벨당 10. TOWER는 공격 전력 보너스, SUPPLY는 공격 쿨다운 단축. 정산 후 삭제
- **F-11.9 영토 정찰**: 정찰 유닛 1기를 소모해 대상 영토의 **총 방어 병력 수만** 확인. 유닛 종류·Zone 분포·건물 배치는 비공개(정보 비대칭). 자기 영토는 정찰 불가
- **F-11.10 주둔 병력 조회**: 특정 영토에 배치된 **본인 유닛**의 타입별 합계 조회. 회수 대상 선택 UI에 사용 — 타인 병력은 집계되지 않는다
- **F-11.11 레벨 반영 전투**: ATK/DEF는 유닛 레벨별 스펙(`unit_type_level_specs`)으로 계산한다. 투입 병력은 `siege_forces`에 레벨과 함께 커밋되어 잠기고, 정산 후 생존분만 원래 스택으로 복귀


### F-12. 공격권 (Attack Token)

- **F-12.1 일반 공격권**: GP `ATTACK_TOKEN_GP_COST` 또는 AP `ATTACK_TOKEN_AP_COST`(config) 지불 시 1개 지급. 랜덤 건물에 피해
- **F-12.2 정밀 공격권**: AP 전용. 목표 건물 우선 지정 기능 제공
- **F-12.3 소선 방식**: 공격 선언 시 자동 차감. 취소 시 토큰 반환 없음
- **F-12.4 경제 역할**: 공격권은 GP 소비의 주요 싱크(Sink)로 과잉 GP 공급 조절

### F-18. 유닛 연구 시스템

- **F-18.1 연구 현황 조회**: 계정 단위 유닛별 `researchedLevel` / 진행 중 목표 레벨 / 완료 예정 시각 조회. 완료 시각이 지난 연구는 조회 시점에 지연 반영된다
- **F-18.2 유닛 레벨 연구**: 목표 레벨 = 현재 + 1. 필요 연구소(RESEARCH_LAB) 레벨 = 목표 − 1, 비용 `2000 × 목표레벨` GP(**금고** 차감), 소요 `30분 × 목표레벨`. 유닛당 동시 1건
- **F-18.3 레벨별 스펙 관리**: 공격력·방어력·생산 식량·필요 병영 레벨을 레벨 단위로 관리자 페이지에서 편집 (`unit_type_level_specs`)
- **F-18.4 레벨 선택 생산**: 유닛 생산 시 해금된 레벨 이하를 선택. 스택 식별자는 (유저 × 유닛종류 × 레벨 × 귀속위치 × 배치)

### F-13. 영토 등급 시스템

- **F-13.1 등급 부여**: 맵 시드 초기화 시 S/A/B/C/D 등급을 `spawn_rate` 확률로 무작위 부여. **이후 변경 불가**
- **F-13.2 생산 배율**: `Territory.base_production_rate × TerritoryGrade.production_multiplier`
- **F-13.3 시작 경매가**: `Auction.start_price × TerritoryGrade.auction_price_multiplier`
- **F-13.4 사전 배치 건물**: S급 2~3개, A급 1개 건물이 낙찰 시점에 자동 생성. 낙찰자 즉시 소유
- **F-13.5 UI 표시**: 영토 팝업 모달 상단에 등급 배지 항상 노출. 비로그인 포함 모든 유저 조회 가능

### F-14. 토지세 시스템

- **F-14.1**: 매일 `LAND_TAX_COLLECTION_HOUR`(config)에 스케줄러가 누진 세율대로 GP 일괄 차감
- **F-14.2**: 면제 구간 = `LAND_TAX_EXEMPT_COUNT`개. 시즌 패스 보유 시 +`SEASON_PASS_TAX_EXEMPT_BONUS`개 추가 면제
- **F-14.3**: 차감 실패 시 주의 알림 + `LAND_TAX_GRACE_PERIOD_HOURS` 유예
- **F-14.4**: 유예 기간 내 납세 실패 시 가장 낮은 등급(D → C → B → A → S 순) 영토부터 순차 강제 경매 전환. 낙찰 대금이 미납 세금 이상이면 즉시 처분 중단. **무적 상태·보호 기간 무시**
- **F-14.5 납세 로그**: 매 차감 시 `land_tax_logs`에 `PAID` / `FAILED` 상태로 기록
- **F-14.6 예외**: Home Island는 영토 수 집계에서 제외

### F-15. 아이템 샵 (Item Shop)

- **F-15.1 무적권**: AP `ITEM_INVINCIBILITY_COST_AP`(config) 지불 시 1개 지급. 사용 시 지정 영토 보호 시간 `ITEM_INVINCIBILITY_EXTEND_HOURS`만큼 연장. 영토당 중복 적용 제한
- **F-15.2 공격권(일반)**: GP `ATTACK_TOKEN_GP_COST` 또는 AP `ATTACK_TOKEN_AP_COST`. F-12.1과 동일 로직
- **F-15.3 공격권(정밀)**: AP 전용. F-12.2와 동일 로직
- **F-15.4 GP 구매권**: AP `ITEM_GP_PURCHASE_COST_AP` 당 `ITEM_GP_PURCHASE_AMOUNT` GP 즉시 지급. 일일 `ITEM_GP_PURCHASE_DAILY_LIMIT`회 초과 시 403 거부
- **F-15.5 구매 로그**: `item_purchases`에 유저/아이템/수량/시각 기록

### F-16. 시즌 패스

- **F-16.1 구매**: AP `SEASON_PASS_AP_COST`(config) 지불 시 `user_season_passes` 생성. 중복 구매 시 기존 `expires_at`에서 날수 누적
- **F-16.2 혜택 적용** (`is_active = true` AND `expires_at > now()` 조건):
  - 섬 생산량: `HOME_ISLAND_PRODUCTION_RATE × (1 + SEASON_PASS_ISLAND_BONUS_PCT / 100)`
  - 건설 일꾼: 동시 건설 `1 + SEASON_PASS_EXTRA_BUILDERS`개 허용
  - 토지세 면제: +`SEASON_PASS_TAX_EXEMPT_BONUS`개
- **F-16.3 상태 표시**: GNB에 패스 활성화 배지. 미보유 시 구매 유도 버튼
- **F-16.4 만료 알림**: `expires_at` 3일 전, 만료 당일 08:00에 알림 발송
- **F-16.5 토지세 복원**: 패스 만료 다음 징수 시점부터 `LAND_TAX_EXEMPT_COUNT` 기본값으로 복구
